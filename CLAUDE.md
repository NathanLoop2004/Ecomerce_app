# Estilo de código

No escribas comentarios. El código se explica solo con buenos nombres y buena estructura. Si algo necesita explicación de verdad, decilo en la respuesta, no en el archivo.

# Idioma

Todo lo que es texto para leer va en español: las respuestas, los títulos y el contenido de los archivos markdown, la documentación.

El código queda en inglés: nombres de variables, funciones, tipos, interfaces, archivos y carpetas. Los campos que vienen de una API externa se dejan tal como los manda la API, nunca se traducen.
